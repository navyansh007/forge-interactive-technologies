# Forge Interactive Technologies

Website for Forge Interactive Technologies. Built with Next.js 15 (App Router), TypeScript, and Tailwind CSS.

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- **Framework**: Next.js 15, App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS + CSS custom properties
- **Fonts**: Space Grotesk, DM Sans, JetBrains Mono via `next/font/google`

## Scripts

```bash
npm run dev      # dev server
npm run build    # production build
npm run start    # serve production build
npm run lint     # ESLint
```
